# Início rápido

Execute executar.bat para abrir o aplicativo compilado, com Java 17 ou superior.

Para executar o código no IntelliJ, adicione todos os JARs de lib às dependências e execute src/Main.java. Mantenha database/dac_ods4.db nesta pasta.

O banco já está incluído. Nenhum CSV é carregado automaticamente. Os anos disponíveis são 2018–2024 e 2026.

Após editar o código, execute compilar.bat para atualizar dac.jar ou execute diretamente pelo IntelliJ. As instruções completas estão em ../README.md.
